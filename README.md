# Description project
Project in machine learning class where it was asked to predict the revenue of a movie given some other characteristics.

The task was to implement and try some models seen during the course, then choose the best model and evaluate its error.


# Description code
The code of the project is separated into 3 files:

- exploration.ipynb: A file were the data structure explored.
- choose_model.ipynb: A file where different models were trained in order to find the best model to predict the revenue.
- final_prediction_KNN.ipynb: this code compute Y2 (the revenue prediction of X2). The KNN model was chosen to make the final prediction.

There is also:
- heatmap/: a folder containing heatmaps of prediction errors for different methods with different parameters

- XX.csv for XX in {X1, Y1}: files containing training data
- XX.csv for XX in {X2, Y2}: files containing features in X2 that were used to predict the revenue in Y2
